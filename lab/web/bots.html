Add a bot

  1. Copy bots/base (C++) or bots/base-py (Python) to bots/<name> and edit bot.json’s name.
  2. Write your strategy in choose() / evaluate(). The view you get is a real GameState (C++) or its JSON (Python), with fog applied.
  3. Press Refresh, then Test to play a 3-turn protocol game against itself. Bots under bots/ appear automatically.

Engine runtime

Matches, self-play and analysis run on a snapshot of engine/, lab/native/ and the bot SDKs, built once per content hash with -ffp-contract=off. Editing the engine creates a new runtime for new matches; existing matches keep theirs.
